# Лабораторная работа №1: калькулятор и конвертер (toolkit)

1) **Калькулятор (calc)**:
   - Считает базовые операции: *, /, //, %, +, -
   - Умеет работать со скобками и правильно учитывает приоритет
   - Понимает унарные знаки. Например: -2, --2, +-2, ++2 и тд

2) **Конвертер величин (convert)**
   - Поддерживает:
     - Длины: миллиметры (mm), сантиметры (cm), метры (m), километры (km)
     - Массы: граммы (g), килограммы (kg)
     - Температура: Цельсий (c), Фаренгейт (f), Кельвин (k)
     - Нельзя конвертировать разные типы. Например: граммы с массами и тд

## Примеры запуска

python -m toolkit calc "2 + 2"
python -m toolkit calc "(2 * 3) - 2"
python -m toolkit calc "(12.5 - 10) + 1"

python -m toolkit convert 1500 --from mm --to m
python -m toolkit convert 2.5 --from kg --to g
python -m toolkit convert 0 --from c --to f
